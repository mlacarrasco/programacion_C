# Videos de ejemplo

GitHub no reproduce archivos `.mp4` al abrir la vista de blob (solo permite descargarlos) y tampoco renderiza el tag `<video>` dentro de sus páginas Markdown (lo elimina por seguridad). Por eso cada video tiene un archivo `.md` con un enlace a [jsDelivr](https://www.jsdelivr.com/), un espejo público y gratuito de este repositorio que sí sirve los `.mp4` con el tipo de contenido correcto, para que el navegador los reproduzca directamente al hacer clic.
